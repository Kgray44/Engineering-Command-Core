# Merge Control Center

Select **Pull requests** to search the configured repository's bounded feed. Choose a pull request to read its source head and base, author, changed files, and requested reviewers. The detail link opens GitHub and Actions evidence. Linked engineering work uses repository-scoped Task records and stored integration runs. The pull request view marks references to earlier revisions and separates recorded integration evidence from current GitHub source. Filter discovery by inspection state or sort by recent activity. A run can be opened directly with its own URL. If the exact GitHub read is unavailable, the selected PR can still show its last observed repository feed entry and a link to GitHub when available. Use **GitHub connection settings** for credential and rate-limit observations, then refresh the source. Inspection requires a verified current head. A PR from outside the current feed can be opened with the application's `#merge?pr=<number>` link.

**Inspect source** sends the displayed GitHub head to the existing integration engine. The engine validates the candidate, checks the branch policy and source state, and records evidence, blockers, and required checks. A last observed integration state belongs to its stored SHA. Review the current GitHub head and the run evidence before authorizing an action. The **Integrate Task** view selects accepted Task candidates through the canonical Task path.

Open a run in **Integration history** for the source, check state, prior repair attempts, action receipts, and verified landed revision when available. Failed workflow and job links open the check at GitHub. Rerun, repair, publication, and merge controls depend on current backend eligibility and authorization. The integration engine verifies exact source, review, checks, and landed ancestry. Branch protection remains authoritative.

The two owner-private staging Sites support evidence inspection. Production GitHub mutation gates remain in the [Phase 1B runbook](../PHASE1B-SITES.md). Keep qualification PRs draft and use fixtures to exercise write controls.

In **Merge Control Center**, use **Preview required checks** to read the configured check contexts, exact-head results, and available failed job links without creating an integration run. The preview retains independent blockers such as a draft PR, conflict, or changed target base. Starting protected integration still requires its own inspection and exact-candidate review.
